# הכנות למוצאי שבת — ענף `motzash-prep`

כל הקוד כאן **לא פורסם לאתר החי** (עובד בענף נפרד). לפרסום: למזג ל-`main`.

## מה כבר מוכן בענף (קוד + נבדק מקומית)
1. **אזור אישי ❤️** — כפתור שמירת ספרים + סינון "הספרים שלי" (localStorage). עובד מיד אחרי מיזוג, בלי תלות בכלום.
2. **הטמעת תוכנת הניהול בעמוד הראשי** — לחיצה על "תוכנת ניהול הספרים" פותחת iframe מלא בתוך העמוד, עם כניסה אוטומטית (handoff). עובד מיד אחרי מיזוג.
3. **מעבר הרשמות/קשר ל-Supabase** — הקוד מוכן, אבל **דורש הרצת SQL + בדיקה חיה** (ראה למטה).

## ⚠️ חובה לפני מיזוג ה-main — להריץ SQL
לפתוח Supabase → SQL Editor → להריץ את `_motzash/registrations.sql`.
הוא יוצר טבלאות `members` ו-`submissions` עם RLS:
- כל אחד יכול להגיש (INSERT) — הרשמה/פנייה ציבורית.
- רק מנהל (is_mgr, דרך header x-mgr-token) קורא/עורך — **מידע אישי נשאר פרטי**.

## מה לבדוק חי אחרי הרצת ה-SQL (יחד, במוצ"ש)
- [ ] להירשם מהאתר (טופס הרשמה) → לוודא שהרשומה נכנסה ל-`members`.
- [ ] להיכנס כמנהל → "חברים רשומים" → לוודא שהרשומה מופיעה, אישור/מחיקה/ייצוא CSV עובדים.
- [ ] לשלוח טופס "צור קשר" → לוודא שנכנס ל-`submissions` (kind=contact).
- [ ] לוודא שמשתמש רגיל (בלי טוקן מנהל) **לא** מצליח לקרוא את הטבלאות (פרטיות).
- תלוי ב-`is_mgr()` הקיים שקורא את ה-header. אם שמות ה-policy מתנגשים — לשנות שם ולהריץ שוב.

## נותר לעשות (לא בוצע עדיין)
- **בקשות ספר (📷)** — כרגע נשמרות ב-`site_settings` (שהוא ציבורי-לקריאה) יחד עם טלפון המבקש. להעביר ל-`submissions` הפרטי ולתקן את מסך "פניות מבקרים" בהתאם. (נקודת פרטיות קיימת מראש.)
- **התראת מייל** על כל הרשמה (Resend/Cloudflare) — אופציונלי.
- **העברת הדומיין** bethyoseflibrary.com ל-Cloudflare + סגירת Netlify.
- **מפתח AI** (AI_API_KEY) ב-Cloudflare לסריקת ספרים.
- **סיסמת admin123** → להחליף.
- **ניקוי כפילויות** בדף הניהול (להבהיר מול אהרן מה בדיוק).

## סדר מומלץ למוצ"ש
1. הרצת `registrations.sql` ב-Supabase.
2. בדיקת לולאת ההרשמה חיה (הרשימה למעלה).
3. השלמת בקשות הספר → submissions.
4. מיזוג `motzash-prep` ל-`main` (מפרסם את הכל).
5. העברת הדומיין + מפתח AI + סגירת Netlify.
